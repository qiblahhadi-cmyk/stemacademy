Security & privacy safeguards

Required protections for the production implementation.

  • Verified sign-inServer must verify Firebase ID tokens.
  • Trusted rolesRole, active status and class membership come from trusted database records.
  • Class-level isolationStudents can only access records permitted for their own account and class.
  • Protected assessment keysAnswer keys must never be exposed to unauthorized clients.
  • Minimal student dataCollect only information necessary for classroom operation.
  • Audit critical actionsRecord security-sensitive changes on the server.

These are implementation requirements, not a claim that the protections are already active.
